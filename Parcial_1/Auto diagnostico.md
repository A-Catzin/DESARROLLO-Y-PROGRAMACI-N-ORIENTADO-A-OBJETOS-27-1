>Que es la POO?
Utiliza clases y objetos para la estructura, se basa en el modelado de entidades para darles atributos y métodos.

>Que es un objeto?
Es un componente de las clases que contiene sus datos propios y permite operar sobre esos datos 

>Que es una clase?
Una clase es como una plantilla que define los atributos y métodos que tendrán los objetos de ella 

>Que es un método?
Es una función definida dentro de una clase que determina las acciones, operaciones o comportamientos que los objetos de esa clase pueden realizar.

>Que es el lenguaje uml?
Es un estándar gráfico de modelado para la ingeniería de software que permite visualizar, especificar, construir y documentar la estructura y el diseño de un sistema mediante diagramas (como diagramas de clases, de casos de uso o de secuencia).

>Que tipos de datos existen?
Los tipos de datos se dividen principalmente en dos categorías:
>- Primitivos : Enteros (`int`), decimales/flotantes (`float`, `double`), booleanos (`true`/`false`), caracteres (`char`) y cadenas de texto (`string`).
>
>- Compuestos (o complejos): Arreglos (`arrays`), listas, diccionarios, objetos y estructuras personalizadas.
