Problemática en "Riviera Express"

"Riviera Express" es una empresa de envíos urbanos que transporta paquetes y documentos pequeños, pero presenta tres problemas operativos:

  • Cálculo manual de tarifas según peso, volumen y distancia.
  • Riesgo de capturar pesos o medidas negativas que alteran los cobros.
  • Falta de control para agrupar varios paquetes en una hoja de ruta y asignar un repartidor responsable.

Alcance de Nuestra Solución POO

  • Herencia: Superclase Envio con subclases Paquete y Documento.
  • Encapsulamiento: Protección contra números negativos usando get/set y @property.
  • Sobrecarga de 4 Operadores: Uso directo de +, -, * y / entre objetos.
  • Agrupación y Asignación: Clase HojaRuta vinculada a Repartidor.
  • Ciclo de Vida y Limpieza: Constructores __init__, destructores __del__, sin comentarios ni excepciones.

1. Superclase Envio.py (get y set)

class Envio:
    def __init__(self, codigo, peso, distancia):
        self.codigo = codigo
        self.__peso = peso
        self.__distancia = distancia

    def __del__(self):
        print(f"Envío {self.codigo} eliminado")

    def get_peso(self):
        return self.__peso

    def set_peso(self, nuevo_peso):
        if nuevo_peso > 0:
            self.__peso = nuevo_peso
        else:
            print("El peso no puede ser negativo")

2. Subclase Paquete.py (Herencia y @property)

from Envio import Envio

class Paquete(Envio):
    def __init__(self, codigo, peso, distancia, volumen):
        super().__init__(codigo, peso, distancia)
        self.__volumen = volumen

    def __del__(self):
        print(f"Paquete {self.codigo} eliminado")

    @property
    def volumen(self):
        return self.__volumen

    @volumen.setter
    def volumen(self, nuevo_volumen):
        if nuevo_volumen > 0:
            self.__volumen = nuevo_volumen
        else:
            print("El volumen no puede ser negativo")

Sobrecarga en Envio.py (+, -, *, /)

    def calcular_costo(self):
        return (self.__peso * 10) + (self.__distancia * 5)

    def __add__(self, otro_envio):
        return self.calcular_costo() + otro_envio.calcular_costo()

    def __sub__(self, otro_envio):
        return self.calcular_costo() - otro_envio.calcular_costo()

    def __mul__(self, otro_envio):
        return self.calcular_costo() * otro_envio.calcular_costo()

    def __truediv__(self, otro_envio):
        return self.calcular_costo() / otro_envio.calcular_costo()

class HojaRuta:

    @repartidor.setter
    def repartidor(self, nuevo_repartidor):

    def agregar_envio(self, envio):
